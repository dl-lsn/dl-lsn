- 💬 **Feedback:** Actively looking for constructive critiques and technical feedback on my models.

* **Environment:** Git, GitHub, Jupyter Notebooks

## 🚀 Featured Project
### 📈 [USCPI-reconstructions](https://github.com)
A Python tool to reconstruct the U.S. Consumer Price Index (CPI-U) from historical component weights and test predictive models.
* **Current Approaches:** SARIMAX & MARS.
* **Key Exogenous Features:** Analyzing the impacts of housing market data and oil prices.

👉 *Technical suggestions and feedback are welcome in the **Discussions** tab of the repository.*
